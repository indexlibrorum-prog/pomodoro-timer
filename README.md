# あわポモ風タイマー

ADHD 向けポモドーロ「あわわポモドーロ」の設計思想（定期休憩なし／1分のアイドリングで動き出す／記録で報酬系を刺激）に、
StudySync 的な学習管理（教科・プロジェクト、忘却曲線リマインド、カレンダー振り返り）を足した、依存ゼロの単一ページアプリ。

参考記事
- <https://note.com/awawa_adhd/n/n203716fd6e8b>（基本思想・タイマー）
- <https://note.com/awawa_adhd/n/n13860e0392bd>（タスク別管理）
- <https://note.com/noko_app/n/n0effd52ea016>（学習向けの管理・振り返り）

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（HTML / CSS / JS すべて内包） |
| `manifest.json` | ホーム画面アプリ（PWA）の定義 |
| `sw.js` | オフライン起動用のサービスワーカー |
| `icon-180/192/512.png` | アイコン |
| `vendor/zxing-reader.js`, `vendor/zxing_reader.wasm` | バーコード読み取り（zxing-wasm 3.1.2 / MIT） |
| `serve.js` | 動作確認用のローカルサーバー（`node serve.js` → <http://localhost:4173>） |

データはすべてブラウザの localStorage に保存される。サーバーもアカウントも不要。
設定の「データを書き出す／読み込む」で JSON バックアップができる。

## 使い方

1. **1分だけ はじめる** を押す（アイドリング）。まず手をつけるだけ。
2. 1分たつと音が鳴り、**続ける / 休憩する** を選ぶ。無操作なら 15 秒後に自動で続行。
3. 作業中は時間がカウントアップするだけ。**定期的な休憩は入らない**。
4. 疲れたら **休憩する（スキップ）**。休憩時間は測るだけで管理しない。戻りたくなったら戻る。

Space キーで 開始 / 休憩 / 復帰 を操作できる。

### 作業用ノイズ

タイマーの下でブラウン / ピンク / ホワイトノイズを再生できる。音源ファイルは持たず、
起動時にその場で生成してループするので、オフラインでも鳴る。設定で「作業を始めたらノイズを鳴らす」を
ON にすると、開始ボタンと同時に再生される（休憩で止めるか続けるかも設定で選べる）。

iPhone ではロック画面やコントロールセンターの再生コントロールに出るので、そこからも止められる。
本体スイッチが消音になっていると鳴らないので注意。

### 作業記録（フォルダとタスク）

- **フォルダ** = 教科・プロジェクト。色、期間（終了日を過ぎると「終了」表示）を設定できる。
- **タスク** = 細かい作業。予定時間、繰り返し（毎日／毎週）、完了チェック。
- 行をタップで選択 → **決定** でロック。以降の計測がそのタスクに紐づく。
- 設定の「作業記録タブを非表示」で、時間だけ測る従来モードに戻せる。

### 忘却曲線リマインド（資格などの学習用）

フォルダの編集で **資格・学習モード** を ON にしたときだけ、その配下のタスクに
「忘却曲線で復習する」設定が出る。完了チェックを入れると、既定 1 → 3 → 7 → 14 日後の順に
次回復習日が自動でセットされ、その日が来ると画面上部の **今日の復習** に並ぶ。
周期はフォルダごと（設定画面で全体の既定値）に変更できる。

#### 試験日と、周期の自動調整

学習モードのフォルダでは、日付欄が「期間」ではなく **試験日** ひとつになる。
設定すると一覧に「試験まで あと32日」と出る。

「試験日から復習の間隔を自動調整する」（既定 ON）を有効にしていると、次回の復習日は

> 標準の周期。ただし**試験までの残り日数の半分**を超えない

という規則で決まる。序盤は通常の忘却曲線どおりに進み、試験が近づくほど自動的に間隔が詰まって、
必ず試験前にもう一度復習が入る。試験日を過ぎると、そのフォルダは「終了」扱いになり復習も止まる。

#### 復習日の通知（カレンダー連携）

PWA は端末内で通知を予約できないので、**復習の予定をカレンダーに渡して iOS 標準の通知を鳴らす**。

学習モードのフォルダで **📅 カレンダーへ** を押すと、これから先の復習日と試験日をまとめた
`.ics` ファイルが共有シートで開くので、「カレンダー」に追加する。予定にはアラームが付いている。
通知の時刻は設定の「復習の予定時刻」（既定 9 時）で変えられる。

復習を消化すると次回日が変わるので、**ときどき押し直して入れ直す**運用になる。

### 参考書をバーコードで登録

学習モードのフォルダの中でだけ **📷 参考書** ボタンが出る。押すとカメラが起動するので、
本の裏の**上段バーコード（978/979 で始まる ISBN）**を枠に合わせる。下段の価格コードは無視される。

読み取ると Google Books と openBD（国立国会図書館の書誌がベース）の両方に問い合わせ、
書名・著者・出版社・書影を取得してその本のフォルダを作る。あとは配下に「第1章」などのタスクを
足していけば、参考書ごとの学習時間が積み上がる。

- 同じ ISBN を再度読んでも二重登録されず、既存の本が選択される。
- 書誌が見つからない本・カメラが使えない環境では、**ISBN 13桁の手入力**で同じことができる。
- 書影は端末内に縮小して保存する（オフラインでも表示される）。書影が公開されていない本も多く、
  その場合は 📕 アイコンになる。
- カメラは https もしくは `http://localhost` でしか使えない（ブラウザの仕様）。

### ダッシュボード

- **7日グラフ** … 「タスク別」で日ごとの積み上げ表示。階層 1〜3 で集計の粒度を変えられる。
- **カレンダー** … 学習時間の濃淡ヒートマップ。日付の下に分数、下部に月合計と実施日数。

## iPhone で使う（PWA）

`file://` のままでは PWA にできないため、**https で配信する**必要がある。

推奨は次のどちらか。

1. **Netlify Drop** — <https://app.netlify.com/drop> にこのフォルダをドラッグ&ドロップ。
   URL が発行されるので iPhone の Safari で開く。アカウント登録なしでも一時 URL が使える。
2. **GitHub Pages** — このフォルダを push して Settings → Pages を有効化。URL が固定で使い続けられる。

いずれも Safari で開いたあと、**共有 → ホーム画面に追加**。全画面のアプリとして起動する。
iOS 26 ではホーム画面に追加したサイトは既定でウェブアプリとして開く。

> **URL は固定にすること。** 記録はブラウザのオリジン（URL のドメイン）ごとに保存されるので、
> 配信先の URL が変わると過去の記録は読めなくなる。Netlify Drop の使い捨て URL ではなく、
> GitHub Pages のように URL が変わらない置き場所を選ぶこと。
> URL を移すときは、先に設定からバックアップを書き出し、新しい URL で読み込む。

### データは消えないのか

ホーム画面に追加したウェブアプリは、Safari の「7日間使わなければ保存データを消す」仕組みの対象外で、
使用日数のカウンタが独立しており、使うたびにリセットされる。毎日使うぶんには消えない。
ただし数週間まったく起動しないと iOS 側の判断で消える可能性は残るため、バックアップ機能を用意している。

- 設定 →「書き出す」で、iPhone では**共有シート**が開く。「ファイルに保存」で iCloud Drive に置いておける。
- 前回の書き出しから 2 週間たつと、画面上部にバックアップを促す案内が出る（「あとで」で 3 日後に再表示）。
- 復元は設定 →「読み込む」から JSON を選ぶ。

### iOS での制限

- バックグラウンドでは JavaScript が止まるが、時刻ベースで計算しているので**復帰後の経過時間は正しい**。
  ただし裏に回している間は通知音が鳴らない。
- 通知音はサイレントスイッチが ON だと鳴らない。
- 「画面を消灯させない」（Screen Wake Lock）は iOS 16.4 以降の Safari で有効。
- データは Safari の localStorage。長期間未使用だと iOS に消される可能性があるため、
  ときどき設定から JSON を書き出しておくと安全。
- iOS Safari はブラウザ標準のバーコード API（`BarcodeDetector`）に非対応なため、
  WebAssembly のデコーダ（`vendor/`、約 1.1MB）を同梱している。初回だけ読み込みが走り、
  以降はキャッシュされる。

## 外部への通信

通常の利用ではどこにも通信しない。**参考書を登録するときだけ**、ISBN を次のサービスに送って書誌情報を取得する。

- `www.googleapis.com`（Google Books API）
- `api.openbd.jp`（openBD）
- `ndlsearch.ndl.go.jp`（書影のみ）

外部に問い合わせたくない場合は、`index.html` の `lookupIsbn()` を空の結果を返すよう書き換えれば、
ISBN と書名の手入力だけで運用できる。
